# 医学教材问答系统 - 项目完成报告

## 📋 项目概览

**项目名称**: 基于RAGFlow与DeepSeek的医学教材问答系统  
**开发时间**: 2025年12月  
**Python版本**: 3.7+ 兼容  
**项目状态**: ✅ 完成部署和测试

## 🎯 项目目标

构建一个智能的医学教材问答系统，能够：
- 处理医学PDF文档并提取结构化知识
- 基于向量检索实现语义搜索
- 提供准确的医学问答服务
- 支持引用溯源和置信度评估

## 🏗️ 系统架构

### 核心组件

1. **医学文档处理引擎** (`scripts/medical_document_parser.py`)
   - PDF文本提取和预处理
   - 章节结构识别和语义分块
   - 医学术语词典支持
   - 知识链完整性分析

2. **DeepSeek API集成** (`scripts/deepseek_integration.py`)
   - 医学专用提示词模板
   - 智能问答生成
   - 引用溯源机制
   - 备用回复策略

3. **向量检索引擎** (`scripts/vectorization_engine.py`)
   - 文本向量化处理
   - 混合检索策略（向量+关键词）
   - 重排序模型支持
   - 语义相似度计算

4. **轻量级问答系统** (`lightweight_medical_qa.py`)
   - Python 3.7+ 兼容版本
   - 医学术语自动识别
   - 关键词检索和排序
   - 批量处理支持

### 配置系统

- **RAGFlow配置** (`configs/ragflow_config.json`)
- **检索策略** (`configs/retrieval_config.json`)
- **分块策略** (`configs/medical_chunking_config.json`)
- **环境变量** (`.env`)

## 💡 技术特性

### 医学专业化
- **医学术语词典**: 疾病、解剖、检查、药物、症状5大类别
- **知识链识别**: 病因-病理-临床表现标准模式
- **医学分块策略**: 知识完整性优先的智能分块

### 检索优化
- **混合检索**: 向量检索(70%) + 关键词检索(30%)
- **重排序模型**: BAAI/bge-reranker-large
- **语义理解**: BAAI/bge-large-zh嵌入模型

### 问答质量
- **置信度评估**: 基于检索相似度的可信度评分
- **引用溯源**: 答案来源追踪和引用生成
- **上下文保留**: 完整的医学知识上下文

## 🔧 使用方法

### 快速开始
```bash
# 运行轻量级问答系统
python lightweight_medical_qa.py

# 运行完整演示
python medical_qa_demo.py

# 执行部署
python deploy_system.py
```

### 自定义配置
1. 修改 `.env` 文件中的API密钥和参数
2. 调整 `configs/` 目录下的检索和分块策略
3. 在 `data/` 目录添加医学PDF文档
