## 🧮 核心算法与逻辑

### 1. 智能问答算法

**算法名称**: 基于关键词匹配的问答系统  
**算法复杂度**: O(n×m) 其中n为问题数量，m为关键词长度  

**核心逻辑**:
```python
def find_best_response(user_question):
    for key_question, response_data in QA_RESPONSES.items():
        # 提取关键词进行匹配
        keywords = key_question.split()
        if any(kw in user_question for kw in keywords):
            return response_data
    return default_response
```

**匹配策略**:
- **完全匹配**: 问题完全一致
- **关键词匹配**: 包含核心关键词
- **模糊匹配**: 相似度阈值判断
- **默认回复**: 无法匹配时的友好提示

### 2. 医学概念搜索算法

**算法名称**: 多字段模糊搜索算法  
**算法复杂度**: O(k×p×q) 其中k为概念数量，p为字段数，q为查询长度  

**搜索字段**:
- 概念名称 (concept_name)
- 定义内容 (definition)
- 症状描述 (symptoms)
- 治疗方法 (treatments)

**搜索逻辑**:
```python
def search_medical_concepts(query):
    results = []
    for name, info in medical_knowledge_base.items():
        # 多字段匹配
        if (query in name or 
            query in info.get("definition", "") or

            results.append(match_score)
    return sorted(results, key=lambda x: x['score'], reverse=True)
```

### 3. 学习进度跟踪算法

**算法类型**: 增量式进度计算  
**计算维度**:
- 时间维度：总时长、今日时长、周时长
- 知识维度：学科掌握度、章节完成度
- 行为维度：连续学习天数、测验准确率

**进度计算公式**:
```
掌握度 = (已完成章节数 / 总章节数) × 权重系数
连续天数 = 连续有学习记录的天数
准确率 = 正确答题数 / 总答题数
```

### 4. 概念对比分析算法

**算法名称**: 多维度属性对比算法  
**对比维度**:
1. 定义对比 (Definition Comparison)
2. 病因对比 (Etiology Comparison) 
3. 症状对比 (Symptom Comparison)
4. 诊断对比 (Diagnosis Comparison)
5. 治疗对比 (Treatment Comparison)
6. 预后对比 (Prognosis Comparison)

**相似度计算**:
```python
def calculate_similarity(concept_a, concept_b):
    similarity_score = 0
    total_dimensions = 6
    
    for dimension in COMPARISON_DIMENSIONS:
        if concept_a[dimension] == concept_b[dimension]:
            similarity_score += 1
    
    return (similarity_score / total_dimensions) * 100
```

## 📡 API接口设计

### RESTful API 规范

| 方法 | 路径 | 功能 | 请求体 | 响应格式 |
|------|------|------|--------|----------|
| POST | `/api/ask_question` | 智能问答 | `{question: string}` | `{answer: string, confidence: float}` |
| POST | `/api/search_concepts` | 概念搜索 | `{query: string}` | `{concepts: array}` |
| GET | `/api/get_concept_detail/<name>` | 概念详情 | - | `{concept: object}` |
| POST | `/api/update_progress` | 更新进度 | `{study_time: number}` | `{success: bool, progress: object}` |
| GET | `/api/get_progress` | 获取进度 | - | `{progress: object}` |
| POST | `/api/compare_concepts` | 概念对比 | `{concept_a: string, concept_b: string}` | `{comparison: array}` |
| POST | `/api/quiz_start` | 开始测验 | `{type: string, chapter: string}` | `{quiz_id: string, questions: array}` |

### API响应标准格式

**成功响应**:
```json
{
    "success": true,
    "data": {
        // 具体数据内容
    },
    "timestamp": "2024-01-01T12:00:00Z"
}
```

**错误响应**:
```json
{
    "success": false,
    "error": {
        "code": "ERROR_CODE",
        "message": "错误描述信息",
        "details": {}
    },
    "timestamp": "2024-01-01T12:00:00Z"
}
```

```
  文本输入    表单校验    HTTP请求   业务逻辑   匹配算法   数据存储   JSON响应   页面更新
```

   ```
   搜索词 → 分词处理 → 多字段匹配 → 相关度排序 → 结果过滤 → 搜索结果
   ```
