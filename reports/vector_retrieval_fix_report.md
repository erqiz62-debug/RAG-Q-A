**融合算法**：
```python
# 创建候选结果映射
candidate_map = {}

# 处理向量检索结果 (权重: 0.7)
for result in vector_results:
    fusion_score = 0.7 * result['vector_score']
    
# 处理关键词检索结果 (权重: 0.3)  
for result in keyword_results:
    fusion_score = 0.3 * result['keyword_score']
    
# 融合相同chunk的分数
if chunk_id in candidate_map:
    candidate_map[chunk_id]['fusion_score'] += fusion_score
```
